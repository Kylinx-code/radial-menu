右键轮盘菜单（Quicker 风格复刻） 使用说明
================================================

【部署到另一台电脑（无需装 Python）★】
  从 GitHub Releases 下载的文件名为英文，下载后可改成任意中文名，功能不变。
  已提供两个打包好的 exe，同事电脑不用装 Python 或任何依赖：

  方案A · 安装包（推荐，有快捷方式和卸载）：
    1. 把「RadialMenu-setup.exe」拷到同事电脑，双击运行。
    2. 弹窗询问是否开机自启，按需选“是/否”。
    3. 安装完成后，桌面和开始菜单会有「右键轮盘菜单」快捷方式，
       双击即可运行；开始菜单里还有「卸载右键轮盘菜单」。
    程序装在 %LOCALAPPDATA%\RadialMenu，配置和日志也在该目录。
    卸载：运行开始菜单里的卸载快捷方式，或再次运行安装包加 --uninstall 参数。

  方案B · 免安装版（最省事，拷过去直接用）：
    把「RadialMenu-portable.exe」单独拷到任意电脑，双击即运行。
    不需要安装，配置 folders.json 和日志 logs\ 会在 exe 同目录自动生成。
    缺点：没有桌面快捷方式和自动卸载，需手动放快捷方式。

  两种方案的功能完全一样，都不依赖 Python；区别只在“是否帮你建快捷方式/自启/卸载”。
  注意：exe 是 64 位程序，需 Windows 10/11 64 位系统。首次运行若安全软件提示，
  选允许/信任（程序用了全局鼠标钩子，属正常，无联网行为）。

【本机开发调试怎么启动】（下面这些是源码方式，需要 Python 环境）
【怎么启动】
  推荐：双击「启动轮盘菜单.vbs」——完全后台运行，没有黑色终端窗口，
        双击后什么都不显示，直接生效。程序无主界面。
  备用：双击「启动轮盘菜单.bat」——会带一个黑色控制台窗口（里面有运行日志），
        只在排查问题时用；日常请用上面的 vbs。

  注意：第一次启动后，如果之前用 bat 开过旧实例，请先用托盘退出或任务管理器
        结束掉再启动 vbs，避免两个实例抢同一个鼠标钩子。

【怎么使用】
  1. 在任意地方，按住鼠标【右键】不要松开。
  2. 朝一个方向拖动鼠标，拖动超过约 18 像素后，
     会在你按下右键的位置弹出一个 3 层玫瑰轮盘（共 24 格）。
  3. 鼠标的【方向】决定选哪一列（8 个方向），
     鼠标离中心的【远近】决定选哪一层（内环/中环/外环）：
       靠中心 = 内环，拖到中间 = 中环，拖到最外 = 外环。
     高亮的花瓣就是当前选中格，中心圆会显示名称和所在环。
  4. 松开右键 -> 立即打开高亮格对应的文件夹。

  注意：
  - 只是单击右键（不拖动）：系统原生右键菜单照常弹出。
    （内部机制：为了彻底阻止拖拽时误弹菜单，程序会先拦下右键再重放一次，
      所以原生菜单可能会有极轻微的延迟，属正常现象。）
  - 拖出轮盘后按 Esc：取消本次操作，不会打开任何文件夹。
  - 轮盘窗口是半透明且鼠标穿透的，不会挡住你正在看的窗口。
  - 思维导图/绘图等软件里右键是"拖画布"的，可加入排除列表，
    这些软件内右键完全不触发轮盘（详见下面【排除程序】章节）。

  【已修复的问题（含性能）】
  1. 之前拖拽后桌面仍会弹出原生右键菜单 —— 现改为从源头拦截右键，
     拖拽时绝不会再弹菜单。
  2. 之前多次打开文件夹后资源管理器卡死 —— 根因是鼠标钩子与打开文件夹
     挤在同一线程，文件夹操作卡住时拖垮了系统鼠标输入。现已把钩子线程
     与界面线程彻底分离，打开文件夹也改为异步，不会再卡死系统。
  3. 右键单击桌面后快速移动鼠标导致桌面卡住 —— 根因是"纯单击重放右键菜单"
     时在鼠标钩子回调里同步调用了 mouse_event 合成事件，造成事件重入、
     堵住输入队列；且合成事件曾被误认成新点击，引发无限递归弹菜单。
     现改为：重放放到独立工作线程异步执行（钩子回调立即返回，实测每次回调
     耗时 < 0.05ms），并给合成事件打特殊标记，钩子读到标记直接放行，
     彻底杜绝递归。单击后随意快速移动鼠标都不会再卡。
  4. 拖拽松手后不打开文件夹、反而弹出桌面右键菜单 —— 根因是"打开文件夹"
     和"重放右键菜单"两个内部消息误用了同一个编号，打开指令被当成了
     重放指令执行。现已改为不同编号，并加了冲突检测防止再犯。
     现在：拖拽 = 打开文件夹，单击 = 弹原生菜单，两条路径彻底分开。
  5. 鼠标指 A 格、却高亮/打开了 B 格（位置对不上）—— 根因是轮盘贴近屏幕
     边缘时会被自动推回屏幕内显示，但"鼠标落在哪一格"的判定仍按原始按下
     点当圆心算，两者中心错开，导致整体偏一格。现已统一：显示位置和命中
     判定共用同一个"推回屏幕后"的轮盘圆心，鼠标指哪就高亮哪、松手就开哪。
  6. 越界取消手势（新增功能）：把鼠标甩出轮盘一定范围，轮盘里所有高亮立即
     取消，中心显示"已取消 / 松手不打开"；此时松开右键不会打开任何文件夹，
     也不会弹出桌面原生菜单 —— 相当于"算了，不选了"。一旦甩出范围，本轮
     就作废，之后即使把鼠标移回轮盘内也不会恢复，必须松开右键重新操作。
     有效范围 = 最外环外缘(outer_radius) + 取消余量(cancel_margin)，
     默认 216 + 80 = 296 像素（从轮盘圆心算起）。
     想调松紧就改 folders.json 里的 cancel_margin：调大 = 要甩得更远才取消，
     调小 = 稍微出界就取消；设为 0 表示一到最外缘就算越界。
     注意：① 判越界用的是"推回屏幕后"的轮盘真实圆心，不是右键按下点，屏幕
     边缘也不会算错；② 松手坐标也会再判一次越界，防止快速甩动时中途鼠标
     移动事件被系统合并/丢弃导致漏判；③ 纯单击(位移<trigger_distance)不受
     影响，照常弹原生右键菜单。
     另：不能用"查右键物理状态"判断松手——右键按下事件被程序吞掉以阻止
     原生菜单，系统并不认为右键已按下，物理状态检测会误判松手导致轮盘"一闪
     而过"，此方案已彻底移除。

【排除程序 —— 让指定软件的右键完全不被接管 ★】
  用途：XMind、MindMaster、亿图脑图、draw.io、Figma、CAD 这类软件里，
        右键往往是"拖拽画布 / 平移视图"。如果轮盘在这些软件里弹出来，
        就会抢走手势、导致画布拖不动。把软件加进排除列表即可解决。

  效果：在排除程序内按住右键 → 程序完全放行（不吞事件、不弹轮盘、
        不打开文件夹、也不重放菜单），软件自己的右键手势原样工作；
        在桌面和其他软件里轮盘照常可用。

  做法一（推荐，不用查进程名）：
    1. 右键点击屏幕右下角托盘图标 → 「识别并添加排除程序（5秒）」。
    2. 立刻把鼠标移到那个软件的窗口里停住（前 2~3 秒是留给你移鼠标的，
       程序只取最后 2.5 秒的采样结果）。
    3. 5 秒后弹窗显示识别到的程序名和窗口标题，点「是」即自动写入
       folders.json 并立即生效，不用重启程序。
    4. 可随时用托盘「查看排除列表」核对已加的程序。

  做法二（手动编辑）：
    用记事本打开 folders.json，在顶部找到这两个字段：
      "exclude_processes": ["XMind.exe", "MindMaster.exe"],
      "exclude_titles":    ["思维导图"],
    保存后托盘 →「重新加载配置」生效。
    · exclude_processes 填进程名关键字，不区分大小写、按"包含"匹配，
      所以写 "xmind" 就能命中 XMind.exe；也支持通配符 "*mind*.exe"。
    · exclude_titles 是可选的窗口标题关键字，某些软件进程名是通用的
      （比如 electron.exe），这时用标题区分更准。
    · 列表为空 = 不排除任何程序（默认）。

  注意：
    - 判定用的是"鼠标所在窗口"的进程（外加前台窗口兜底），
      每次右键按下只查一次，且按进程 ID 缓存进程名，几乎零开销。
    - 别把 explorer.exe 加进去，否则桌面和资源管理器里轮盘也会失效；
      一键识别时如果检测到的是 Windows 桌面，弹窗会有明确警告。
    - 排除是否生效可看日志：命中时会记一行「[排除] 放行右键 · 程序=xxx」。
    - 识别窗口用的都是系统自带 API，无任何联网行为。

【3 层 24 格是怎么排的】
  轮盘 = 3 个同心环 × 每环 8 个方向 = 24 格。
  在 folders.json 里，顺序就是「先内环 8 个、再中环 8 个、最后外环 8 个」，
  每环内部都按：正上 / 右上 / 正右 / 右下 / 正下 / 左下 / 正左 / 左上。

    第 1~8 项   = 内环（离中心最近）  默认：桌面/下载/文档/图片/工作区/临时/控制面板/回收站
    第 9~16 项  = 中环                默认：音乐/视频/收藏夹/字体/系统32/Windows/C盘/用户
    第 17~24 项 = 外环（最外圈）      默认：外·上/外·右上/…（占位，可改成你常用的）

  记忆技巧：索引 = (层号-1)×8 + 方向号。例如「中环·正右」= 第 2 环第 3 个 = 第 10 项。

【怎么改成我自己的文件夹】
  用记事本打开「folders.json」，改 name（显示名）和 path（路径）即可，
  例如：
      { "name": "医保档案", "path": "D:\\医保档案" }
  改完保存后，右键点击屏幕右下角托盘里的图标 -> 「重新加载配置」即可生效。

  支持三种 path 写法：
    - 普通路径：        %USERPROFILE%\Desktop
    - 环境变量：        %USERPROFILE%\Downloads
    - 控制面板等：      control      （等价于 Win+R 输入 control）
    - 回收站等特殊：    shell:RecycleBinFolder
    - 任意命令：        cmd:notepad  （cmd: 开头表示执行一条命令）

  还可以调灵敏度 / 大小 / 透明度（都在 folders.json 顶部）：
    trigger_distance：拖多远才弹出轮盘（默认 18，调大更不容易误触）
    inner_radius：中心死区 / 最内环内缘（默认 56，鼠标在此范围内不选任何格）
    outer_radius：最外环外缘（默认 216；三环平分 56~216，每环约 53）
                  想要更大的轮盘，就把 outer_radius 调大（比如 260）。
    cancel_margin：越界取消余量 0~400（默认 80）。鼠标离轮盘圆心超过
                  outer_radius + cancel_margin 就取消本轮拖拽（详见上面第 6 条）。
                  调大=要甩更远才取消；设为 0=一到最外缘就算越界。
    opacity：轮盘整体透明度 20~100（默认 92；数字越小越透明，
             比如 70 就能透出桌面内容，50 更透）。想完全不透明填 100。
    render_scale：渲染清晰度倍率 1~4（默认 3；越高字和花瓣边缘越锐利，
                  一般保持 3 即可，低配机器可降到 2）
    exclude_processes / exclude_titles：排除程序列表（详见【排除程序】章节）

  改 name 时别写太长：内环格最窄，建议 ≤4 字，超长会自动截断加省略号。
  清晰度说明：轮盘按 3 倍分辨率绘制再高质量缩小，并声明了高分屏
  DPI 感知，所以在任何缩放比例的屏幕上都不会发虚。

【托盘图标（右键点击它）】
  程序运行时在屏幕右下角托盘有一个蓝色轮盘图标，右键点击它可：
    - 设置 · 打开文件夹配置   -> 用记事本打开 folders.json 编辑 24 格
    - 重新加载配置            -> 改完配置后点这个立即生效
    - 查看运行日志            -> 打开 logs\radial.log 排障
    - 识别并添加排除程序（5秒）-> 自动识别鼠标下的软件并加入排除列表
    - 查看排除列表            -> 弹窗显示当前已排除的程序 / 标题关键字
    - 退出                    -> 关闭程序
  托盘图标用的是专门设计的轮盘图标（app.ico），不是系统默认图标。

【怎么退出】
  - 右键点击托盘图标 -> 退出
  - 或按 Ctrl + Alt + Shift + Q

【运行日志 —— 出问题时找我看这个】
  程序把所有运行记录写进日志文件：
      logs\radial.log      （就在本程序目录下）
  里面带时间戳，记录：程序启动/退出、每次打开哪个扇区和文件夹、
  配置重载、排除程序命中时的「[排除] 放行右键 · 程序=xxx」、
  以及所有错误和警告（如钩子异常、打开失败等）。
  - 日志自动轮转：写满 1MB 另存一份，最多保留 3 份（radial.log.1/.2/.3），
    不会无限增长占用磁盘。
  - 用 vbs 无窗口启动时照样写日志，不需要那个黑框。
  - 如果程序出现任何异常（卡住、不弹轮盘、打开错文件夹等），
    把 logs\radial.log 发给我，我就能看到当时发生了什么、精准定位问题。
  - 想手动看日志：直接双击 logs\radial.log（会用记事本打开）。

【常见问题】
  Q：杀毒软件报毒/拦截？
  A：本程序用了全局鼠标钩子（这是实现"任意位置右键拖拽"的必要手段），
     部分安全软件会提示，选择允许/信任即可。源码就是目录下的 radial_click.py，
     可自行查看，无任何联网或收集行为。

  Q：在管理员权限的程序里（如任务管理器）右键拖动没反应？
  A：Windows 限制低权限进程无法向高权限程序注入鼠标消息。
     以管理员身份运行即可。用 vbs 时：右键「启动轮盘菜单.vbs」没有"以管理员
     身份运行"选项，可右键「启动轮盘菜单.bat」-> 以管理员身份运行（会有黑框，
     属正常）。一般日常使用不需要管理员权限。

  Q：双击 bat 报"xxx 不是内部或外部命令"或路径语法错误？
  A：这是 bat 文件编码问题（UTF-8 中文被 cmd 按 GBK 解读）。
     本目录的 bat 已修复为纯 ASCII + GBK 编码，不会再有此问题。
     如果仍报错，双击「诊断环境.bat」查看 Python 环境和依赖状态。

  Q：提示 ModuleNotFoundError（找不到 win32gui / PIL 等）？
  A：双击「启动轮盘菜单.bat」会自动安装 pywin32 和 pillow。
     若自动安装失败，手动打开命令行执行：
        python -m pip install pywin32 pillow
     注意 python 版本需与 pip 对应（用 python -m pip 而非直接 pip）。

  Q：想开机自动启动？
  A：给「启动轮盘菜单.vbs」建一个快捷方式，放进「启动」文件夹：
     Win+R 输入 shell:startup，回车，把快捷方式拖进去。
     用 vbs 做自启，开机时不会弹黑框。
